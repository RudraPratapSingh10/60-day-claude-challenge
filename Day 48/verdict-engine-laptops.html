🔍 How this was researched

▾

Method: Each data point below comes from a named, publicly checkable source — manufacturer spec sheets, independent lab-tested reviews (PCWorld, Tom's Hardware, Tom's Guide, Notebookcheck, XDA Developers, Engadget, etc.), or iFixit teardown reports. Where sources disagreed or a figure wasn't independently verifiable, that is flagged explicitly below and in the data table with an Estimate badge — nothing is silently smoothed over or invented.

Scoring formula: For each criterion, the four laptops' real values are min-max normalized to a 0–100 scale (best real value in the set = 100, worst = 0). Price and nothing-else-being-equal criteria are inverted so "better" always means a higher score. Display quality uses a disclosed composite: 40% peak brightness + 30% refresh rate + 30% color-gamut tier (tier assigned from the language reviewers used to describe measured gamut coverage). The overall verdict score is the weighted sum of the four normalized criterion scores, using whatever weights you set above.
