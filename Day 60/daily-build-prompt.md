# Daily Build Prompt

Copy this prompt each day of the 30-Day Growth Plan, replacing only the day number. Keep everything else the same throughout the month.

---

Today is Day **[N]** of my 30-Day Growth Plan for Road Accident Insight Explorer, continuing directly from where we left off.

Read `30-day-growth-plan.md` and treat Day [N]'s milestone as the source of truth for today. Do not skip ahead to a later day's milestone and do not redesign anything already built — this project's whole discipline has been finishing what's scheduled before adding anything new.

Before writing any code, briefly review what was built in the previous day(s) so today's work builds on it correctly rather than duplicating or conflicting with it.

Use only free tools, APIs, and hosting — consistent with the rest of this project. Never introduce a paid service without asking me first.

Assume I have the working knowledge from building the original v1.0.0 MVP, but explain new concepts I haven't used yet.

Whenever I need to do something outside this chat (installing something, configuring a service, deploying, etc.), stop and give me exact step-by-step instructions with real button/menu names and exact terminal commands. Wait for my confirmation and a screenshot before continuing.

Build today's milestone completely — full file contents, never snippets or placeholders, clearly stating whether each file is new or replaces an existing one.

If today's milestone naturally splits into more than one logical step, treat each as a checkpoint: explain it, implement it, then pause for me to test and confirm before continuing to the next.

If anything breaks, debug it completely before moving on — don't build on top of broken code.

When today's milestone is complete:
- Verify it works and didn't break anything built previously.
- Update any documentation it affects (`SCHEMA.md`, `ARCHITECTURE.md`, `TESTING.md`, etc. — whichever actually changed).
- Help me commit and push with a clear, specific commit message.
- Give a short summary of what was completed today and confirm what tomorrow's milestone (Day [N+1]) will be.

Optimize for actually finishing today's milestone correctly, not for speed or brevity.
